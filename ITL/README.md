## Quick Demonstration Guide

### 1. One-Click Launch (Web Dashboard)
Double-click `run.bat` or run:
```bash
python app.py
```
Open your browser at:
- **Web Portal & Seat Picker:** [http://127.0.0.1:5000](http://127.0.0.1:5000)
- **Live Interactive Kanban Board:** [http://127.0.0.1:5000/kanban](http://127.0.0.1:5000/kanban)

### 2. Instant Automated Viva Walkthrough (<30s)
```bash
python src/main.py --demo
```

### 3. Run Automated Unit Test Suite
```bash
python -m unittest tests/test_bus_booking.py -v
```

For complete lab instructions, viva questions, and evaluation rubric, see [ITL_LAB_MANUAL.md](ITL_LAB_MANUAL.md).
